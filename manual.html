1PDF Filesとは

PDF Filesは、ブラウザで動くPDFエディタです。PDFに手書きや図形、文字、寸法、署名、印影を書き込み、ページの並べ替えや削除をして、端末やGoogleドライブに保存できます。Gmailでそのまま送ることもできます。

アプリストアは使いません。ブラウザで公開URLを開くだけで使え、ホーム画面に追加(インストール)すると普通のアプリと同じようにアイコンから起動できます。一度開いたあとは、電波のない場所でも編集できます。

データの保存場所開いたPDF、編集中の内容、履歴、印影は、使っている端末の中に保存されます。別の端末とは自動では同期されません。別の端末で続きを作業したいときは、Googleドライブに保存してください。

このマニュアルは、アプリの右上の人型ボタン → マニュアルをダウンロード(PDF)でPDFとして端末に保存できます。

2はじめてのログイン

  1. 公開URLをブラウザで開きます。ログイン画面が出ます。
  2. はじめての人は新規登録を押し、メールアドレス・名前・パスワード(8文字以上)を入力します。登録済みの人はログインでメールアドレスとパスワードを入力します。
  3. ログイン状態を保持するにチェックを入れておくと、次回からログイン画面が出ません。
Buildsと同じアカウントBuildsを使っている人は、Buildsと同じメールアドレスとパスワードでログインできます。一度ログインした端末では、オフラインでもログインできます。

パスワードを忘れたとき

  1. ログイン画面のパスワードを忘れた場合を押します。
  2. 管理者に連絡して、6桁の確認コードを発行してもらいます(管理者は右上の人型ボタン → 再設定コードの発行(管理者)で発行できます)。コードは30分有効で、5回間違えると使えなくなります。
  3. メールアドレス、確認コード、新しいパスワードを入れて再設定してログインを押します。

ログイン中にパスワードを変えるときは、右上の人型ボタン → 設定 → パスワードを変更です。

3インストール(ホーム画面に追加)

インストールすると、ブラウザのアドレスバーなどが消えて画面を広く使え、ホーム画面やスタートメニューのアイコンから起動できます。アイコンは赤い角丸に白い書類と「PDF Files」の文字です。アプリ内でも、ファイル → ホーム画面に追加(インストール)で手順を確認できます。

iPhone・iPad Safari

  1. Safariで公開URLを開きます。
  2. 画面下(iPadは上)の共有ボタン ⬆︎ を押します。
  3. ホーム画面に追加を選びます。見つからないときはメニューを下へスクロールします。
  4. 名前が「PDF Files」になっていることを確認し、追加を押します。

iPhone・iPadは、Safariから追加してください。

Windows Chrome・Edge

  1. ChromeかEdgeで公開URLを開きます。
  2. アドレスバー右端のインストールアイコン(モニターに矢印の形)を押します。アプリ内のファイル → ホーム画面に追加(インストール) → 今すぐインストールでも同じです。
  3. 確認が出たらインストールを押します。

スタートメニューに「PDF Files」が追加されます。タスクバーにピン留めもできます。

Android Chrome

  1. Chromeで公開URLを開きます。
  2. 右上の︙メニュー → アプリをインストール(またはホーム画面に追加)を選びます。
  3. インストールを押します。

ホーム画面とアプリ一覧にアイコンが追加されます。

Mac Chrome・Edge・Safari

  1. Chrome・Edgeは、Windowsと同じくアドレスバーのインストールアイコンから追加します。
  2. Safariは、メニューバーのファイル → Dockに追加を選びます。
PDFをダブルクリックで開くパソコンのChrome・Edgeでインストールした場合、PDFファイルを右クリック → プログラムから開くでPDF Filesを選べます。すでにPDF Filesが開いているときは、そのウィンドウに新しいタブとして開きます。
iPhone・iPadの注意Safariで開いたPDF Filesと、ホーム画面から開いたPDF Filesは、保存データ(履歴・印影・編集中の内容)が別々になります。普段はホーム画面のアイコンから使ってください。

5PDFを開く・新しく作る

何も開いていないときは、画面中央のボタンから始められます。開いたあとはファイルメニューを使います。

  • PDFを開く(この端末):端末の中のPDFを選びます。パソコンでは、PDFを作業画面にドラッグ&ドロップしても開けます。
  • Googleドライブから開く:はじめて使うときにGoogleのログインと許可の画面が出ます。
  • 履歴から開く:前に開いたPDFを、書き込みを残したまま開き直します。
  • 白紙から新規作成:白紙のPDFを作ります。
  • 写真・スキャンから新規作成:カメラで書類を撮影してPDFにします。

同じファイルを二重に開くことはありません。すでに開いているファイルを開くと、そのタブに切り替わります。

開けないPDFパスワード付きのPDFは開けません。パスワードを解除したPDFを開いてください。

6書き込む・図形を描く

下のツールバーで道具を選び、ページの上をなぞります。描いたものは選択ツールで押すと選択でき、移動・大きさの変更・色の変更・削除ができます。

ツール使い方
選択描いたものを選んで動かす・変える・消す。
範囲選択ドラッグで四角く囲んで複数選びます。左から右へ囲むと「完全に入ったもの」、右から左へ囲むと「触れたもの」が選ばれます。Shiftを押しながらタップで追加・解除。選んだ図形はまとめて移動・色変更・複製・削除できます。
投げ縄自由な形に囲んで、完全に入った図形をまとめて選びます。
移動ページを掴んでスクロールします(書き込みはしません)。
ペン指・ペン・マウスでなめらかに手書きします。
消しゴムペンで書いた線をなぞって消します。線ごと消すか、なぞった部分だけ消すかを右のパネルで選べます。
線・矢印ドラッグで引きます。パソコンでは Shift を押しながらで45°刻みになります。
四角・丸ドラッグで描きます。右のパネルで塗りつぶしもできます。
円弧中心から外へドラッグします。半円・1/4円・3/4円は右のパネルで切り替えます。
多角形角をタップして点を打ち、最初の点をタップするか完了で閉じます。あとから頂点を動かせます。
雲ドラッグで雲マーク(指摘・修正箇所の囲み)を描きます。山の大きさ(ピッチ)は右のパネルで変えます。
文字入れたい場所をタップして文字を入力します。

続けて描くとき

線・図形・寸法などは、描いた直後に選択された状態になり、そのまま色や太さを調整できます。何もない所をタップすると確定し、同じツールに戻って続けて描けます。この動きは設定で切り替えられます。

iPadとApple Pencil設定のペン入力モードをオンにすると、描くのはペン(とマウス)だけになり、指はスクロール専用になります。手のひらが画面に触れても線が入りません。

7寸法・縮尺・計測

図面や間取り図に寸法を書き込んだり、長さを測ったりできます。

寸法線を入れる

寸法線ツールで、測りたい2点をドラッグし、表示したい数値(文字も可)を入力します。あとから選択して文字を直せます。

縮尺を設定して長さを測る

  1. 縮尺設定ツールで、実際の長さが分かっている2点(例:図面上の 3,640mm の壁)をドラッグします。
  2. その実際の長さと単位を入力して設定を押します。全ページに同じ縮尺を使うこともできます。
  3. 自動で計測ツールに切り替わります。測りたい2点をドラッグすると、設定した縮尺で長さが表示されます。

用紙と縮尺(1/〇〇)で設定する

縮尺設定ツールまたは右のパネルの用紙と縮尺(1/〇〇)で設定から、用紙サイズ(A3 など)と 1/100 のような縮尺を数字で指定できます。A4 のPDFに縮小した A3 図面が入っている場合も、元の用紙サイズを選べば実寸で計測できます。

スナップ・極トラッキング・数値入力

線・矢印・四角・丸・円弧・多角形などを描くと、すでにある図形の端点・中点・中心・四半円点・交点に自動で吸い付き、緑の印が出ます(F3でオン/オフ)。角度は、設定した刻み(初期値45°、右のパネルで変更)に近づくと自動で合います(F10)。Shiftを押しながら描くと、90°刻みに固定されます。

線・矢印・四角・丸は、ドラッグせず1回クリックすると数値入力の欄が出ます。長さ(四角は幅と高さ、丸は半径)を打ってEnterで確定します。角度を空にすると画面で動かした向きになり、そのままクリックすると画面の位置で確定、Escで中止します。縮尺を設定したページではmmで入力できます。作図中は長さと角度がカーソルの横に表示されます。選んだ線・四角は、右のパネルで長さ・角度・幅・高さを数字で変えられます(最初の点は動きません)。

色や太さを変えると、次に描く図形にその設定が引き継がれます。

円・3点円弧・ポリライン・正多角形

ツールを選ぶと、右のパネルの描き方で切り替えられます。丸は「楕円(対角)」と「円(中心→半径)」、円弧は「中心と半径」と「3点」(通る3点を順にタップ)、多角形は「多角形」「ポリライン(開いた線。ダブルタップか「完了」で終了)」「正多角形(中心から外へドラッグ。辺の数はパネルで指定)」です。選んだ描き方は次回も引き継がれます。

四角・多角形・ポリラインを選ぶと、各辺の中点に四角いハンドルが出ます。これをドラッグすると、その辺だけが垂直方向に動きます。四角・丸・多角形は、パネルの雲マークに変換で改訂雲にできます。

移動・回転・拡大縮小・鏡像・配列・オフセット

図形を選ぶと、右のパネルに修正コマンドが出ます(複数選択でも使えます)。ボタンを押したら、画面の案内に従って点をタップします(端点・中点などには吸い付きます)。やめるときは中止かEscです。

移動・コピー: 図形を選び、修正メニューの「移動」「コピー」(または M / K)で、基点→移動先の順にタップします。基点・移動先は図形の角・中点・交点などにも吸着します。基点を押したまま移動先までドラッグして離す操作もできます(指でも操作しやすくなります)。コピーは続けて何度でも置けます。回転: 角度(右回り)を入れて、中心をタップします。尺度: 倍率を入れて、基点をタップします。鏡像: 軸になる直線の2点をタップします(「元を残す」で左右対称の複製)。回転・尺度・鏡像は「元を残してコピー」もできます。

配列複写(矩形): 行・列の数と間隔を入れて「配列する」。配列複写(円形): 個数と全体の角度(360で一周)を入れて、中心をタップします。オフセット: 距離を入れて、ずらしたい側をタップすると、線・四角・丸・円弧・多角形が平行にずれた複製ができます(四角・丸は外か内かで大きくも小さくもなります)。

画像・スタンプ・署名は、移動とコピーはできますが、回転や斜めの鏡像はできません。丸や四角を斜めに回すと多角形になります。

トリム・延長・フィレット・面取り・切断・ストレッチ・結合・分解

ツールバーの修正ボタンからメニューを開きます(図形を選ばずに始められます)。画面の案内に従ってタップし、続けて何度でも使えます。やめるときは中止かEscです。

トリム: 消したい部分をタップすると、他の図形との交点から交点までが消えます(線・矢印・ポリライン)。延長: 線の端の近くをタップすると、次に当たる図形まで伸びます。フィレット: 半径を入れて、残したい側の2本の線をタップすると、角が円弧で丸まります(半径0なら角をそろえるだけ)。四角・多角形・ポリラインは、丸めたい角の近くをタップするとその角が丸まります(四角は多角形に変わります)。選んだ図形の角を一度に丸めるには「角を全部丸める」を使います。面取り: 距離を入れて、2本の線をタップすると角が斜めに切れます。切断: 線の途中をタップすると、そこで2本に分かれます。

ストレッチ: 動かしたい部分を窓(対角の2点)で囲み、基点→移動先をタップすると、窓に入った頂点だけが動いて図形が伸び縮みします(窓に完全に入った図形は丸ごと動きます)。結合: 端点がつながっている線を選んで押すと、ひとつのポリライン(輪になれば多角形)になります(J)。分解: 選んだ四角・多角形・ポリラインを1本ずつの線にばらします(X)。

寸法の種類を増やす

ツールバーの修正メニューの「寸法を入れる」から、次の寸法を選べます。図形を選ぶ必要はありません。

  • 半径寸法・直径寸法:円または円弧をタップし、寸法を入れる向きの点をタップ。数値を入れると R・⌀ が頭に付きます(縮尺があれば長さを自動表示)。
  • 角度寸法:頂点、1本目の線上の点、2本目の線上の点の順にタップ。角度は自動で表示され、右のパネルで半径や文字を変えられます。
  • 直列寸法・並列寸法:測点を順にタップし、完了(またはEnter、同じ点を2回タップ)で、寸法をまとめて作ります。直列は寸法線が一直線に並び、並列は基準の点から各点までを少しずつずらして重ねます。

寸法線の端点をドラッグして動かすと、数値も新しい2点間の長さに自動で直ります(R・⌀ などの頭の文字は残ります)。寸法値を動かしたときに出る引出線の先端は、パネルの「寸法値の引出線の先端」で黒丸・矢印・なしを選べます。

文字つき引出線

ツールバーの引出線を選び、指したい所から文字を置きたい所までドラッグします。離すと文字を入れる画面が出ます。空のままなら、文字なしの普通の引出線になります。

右のパネルで、文字の囲み(アンダーライン / 丸で囲う / 囲みなし)と先端(矢印 / 黒丸 / なし)、文字の大きさ、先端の大きさ、線の太さを変えられます。アンダーラインでは引出線が文字の下の線の端につながり、丸では数字1つなら円、文字が長ければ長丸になって、引出線は丸の高さの中央から出ます。文字側の端の点をドラッグして文字を動かしても、先端の位置は変わりません。丸で囲うときは、引出線の先から少し水平な線を出してから丸につながります。文字を直すには、図形をダブルタップするか、パネルの文字欄に入力します。直前に選んだ囲み・先端は、次に描く引出線にも引き継がれます。

レイヤー

ツールバー左のレイヤーボタンでパネルを開きます。レイヤーごとに表示/非表示・ロック・色・太さ・線種を設定でき、図形を選択でそのレイヤーの図形をまとめて選べます。レイヤー「0」以外に描いた図形は、色・太さ・線種がレイヤーに従います(図形ごとに個別指定も可)。非表示のレイヤーはPDFにも書き出されません。レイヤーを削除すると中の図形も消えます(取り消しで戻せます)。

8署名・印影・写真

署名

署名ツールで署名を入れたい範囲を四角でドラッグ(タップでも可)し、出てきた欄に指やペンで署名して署名を入れるを押します。

印影(ハンコ)

  1. ファイル → 印影の登録・管理で印影を登録します。ハンコを押した紙の写真、名前からの自動作成、手書きのどれでも作れます。
  2. 印影ツールを選び、押したい位置をタップします。

写真

ツールバーの写真で、カメラで撮った写真や画像ファイルをページに貼ったり、新しいページとして追加したりできます。

9ページの操作

ツールバーのページでページ一覧を開きます。

  • 複数のページを選ぶ:ページのチェックボックスに入れるほか、パソコンではCtrl(Macは⌘)を押しながらページをクリックすると、チェックを付けたり外したりできます。Shiftを押しながらクリックすると、前にクリックしたページからそこまでをまとめて選べます。
  • 並べ替え:ページをドラッグして好きな位置へ動かします。チェックを入れたページをドラッグすると、チェックしたページをまとめて動かせます。
  • 回転:ページの回転ボタンで90°ずつ回します。
  • 削除:ページのゴミ箱ボタンで1ページずつ、チェックを入れてまとめて削除もできます。最後の1ページは削除できません。
  • 追加:白紙ページ(A4縦・横)、別のPDF、カメラの写真、画像ファイルを追加できます。パソコンでは、ページ一覧に別のPDFをドロップするとその位置に入ります。
  • そのページだけ書き出す:チェックを入れたページを書き出しで、そのページだけのPDFにして保存します。パソコン(Chrome・Edge)では保存先を選ぶ画面が開き、最初は今開いているファイルと同じフォルダが表示されます。iPhoneでは共有メニューから"ファイル"に保存などを選びます。
  • ドラッグして保存:パソコンのChrome・Edgeでは、ページをデスクトップやフォルダへドラッグして離すと、その場所にそのページのPDFが保存されます(チェックを入れたページをドラッグすると、チェックしたページ全部が1つのPDFになります)。ページにマウスを乗せた時点でPDFを作り始めるので、乗せてすぐにドラッグして間に合わなかったときや、他のブラウザでは、保存先を選ぶ画面になるか、ダウンロードフォルダに保存されます。

10保存・書き出し・メール

書き込んだ内容は、端末の中に自動で一時保存されます。元のファイルやGoogleドライブへ保存するには、右上の保存・出力を使います。

メニュー内容
上書き保存開いた元のファイルに上書きします。パソコンで開いたPDFはそのファイル、Googleドライブから開いたPDFはドライブのファイルが更新されます。元の場所が分からないファイル(iPhoneで開いたPDFや白紙から作ったPDF)は、保存先を選びます。
Googleドライブに保存上書きするか、別のファイルとして保存するかを選べます。
PDFを端末に保存レイヤーが2つ以上あるときは「レイヤーを残す」を選べます(他のPDFソフトでもレイヤーごとに表示・非表示できます)。ファイル名とファイルサイズの最適化を選んで保存します。パソコン(Chrome・Edge)では保存先を選べ、最初は今開いているファイルと同じフォルダが表示されます。iPhoneでは共有メニューから"ファイル"に保存などを選びます。
DXFで書き出す描いた図形をCAD用のDXFファイル(AutoCAD 2007形式)にして保存します。書き出すページを選びます。縮尺を設定したページは実寸(mm)、未設定のページは用紙上の寸法(mm)です。線・四角・円・楕円・円弧・多角形・ポリライン・雲・文字・寸法・引出線を、レイヤー・色・線の太さ・線種つきで出します。写真・スタンプ・署名と、塗りつぶしは含まれません。寸法は線と文字に分けて出力します。「元のPDFの線も含める」を選ぶと、図面PDFなどの線を別レイヤー「PDF元図」として一緒に出します(文字・画像・塗りは含まれません)。
画像・SVGで書き出す選んだ1ページを PNG・JPEG・SVG のファイルにします。解像度(72/150/300dpi)と、元のPDFの絵を含めるかどうかを選べます。SVGは描いた図形が線のまま残り、拡大しても劣化しません。複数ページをまとめて出すときは、ページ一覧でページを選んで PDF で書き出します。
Gmailでメール送信PDFを添付してGmailで送ります。添付できるのは約24MBまでです。
ファイル名を変更表示中のPDFの名前を変えます。

編集データを残す保存と、焼き込みの書き出し

  • 上書き保存・Googleドライブに保存:PDFの中に編集用データ(図形・文字・寸法とレイヤー)を入れます。他のPDFソフトでは普通のPDFとして開け、このアプリで開き直すと図形とレイヤー(表示/非表示・ロックも)が編集できる状態で戻ります。図形はPDF内の専用レイヤー「PDF Files/レイヤー名」に描かれます。
  • PDFを端末に保存・Gmailで送信・ページの書き出し:編集用データは入れず、図形を焼き込みます。受け取った人は図形を編集できません。
  • 写真・スタンプ・署名は、既定では焼き込みです。設定の「上書き保存・ドライブ保存に入れる編集データ」で「写真・スタンプ・署名も含める」にすると、これらも開き直して動かせます(容量が増えます)。ロックした署名・印影、最小(画像化)は、編集データを入れられません。

ファイルサイズの最適化

  • 標準(画質優先):元のPDFの内容を保ち、挿入した写真だけを適度に圧縮します。
  • 軽量(おすすめ):写真を強めに圧縮します。通常はこれで十分軽くなります。
  • 最小:全ページを画像にして最も軽くします。文字の選択や検索はできなくなります。メールで容量オーバーになったときに使います。

11タブ・別ウィンドウ・履歴

  • タブ:複数のPDFを同時に開けます。ファイル → 開いているファイルで一覧を見られます。
  • 別ウィンドウ:パソコンでは、タブを作業画面の外へドラッグするか別ウィンドウで開く(並べて表示)で、PDFを別のウィンドウに分けて並べられます。
  • 閉じる:アプリを閉じると、開いていたファイルはすべて履歴に入ります。すべて閉じる(履歴へ)も同じです。保存しないで閉じるは、編集を捨てて閉じます。
  • 履歴:ファイル → 履歴から開くで開きます。まだ元のファイルに保存していないものには「未保存(端末内に一時保存中)」と表示され、名前の横の保存で元のファイルに上書き保存できます。ゴミ箱ボタンは、その履歴と端末内の編集データを削除します(Googleドライブに保存済みのファイルは消えません)。

12オフラインで使う

一度インターネットにつながった状態で開けば、アプリ本体が端末に保存されます。その後は機内モードでも、PDFを開く・書き込む・図形・寸法・計測・署名・ページ操作・端末への保存ができます。

Googleドライブへの保存とメール送信は、オフラインのときは「待ち」に入り、上のバーに件数が表示されます。オンラインに戻ると今すぐ実行の案内が出ます。設定でオンライン復帰時に通知で知らせるをオンにすると、通知でも知らせます。

13設定

右上の人型ボタン → 設定で開きます。変えたら保存を押します。

  • Google連携:通常は設定不要です。ドライブやメールをはじめて使うときにGoogleのログインを一度行います。Googleの接続を解除で連携をやめられます。
  • ドライブの選択画面を開く場所:マイドライブ・前回保存したフォルダ・指定したフォルダから選びます。
  • メールの送り方:アプリから直接送るか、Gmailを開いて添付するかを選びます。
  • ボタンの大きさ:自動・標準・大・特大。
  • ペン入力モード、続けて描く動き、オンライン復帰時の通知。
  • マニュアル:人型ボタンのメニューで設定のすぐ下にあるマニュアルをダウンロード(PDF)で、このマニュアルをPDFで保存できます。
  • アプリのバージョン:今のバージョンの確認と更新を確認(バージョン更新を参照)。

14バージョン更新

PDF Filesはアプリストアを通さないので、更新のための操作は基本的に不要です。新しいバージョンが公開されると、インターネットにつながった状態で起動したときに裏で自動的に取り込まれ、次に起動したときから新しいバージョンになります。

新バージョン公開→オンラインで起動(裏で取り込み)→次の起動から新バージョン

今すぐ更新したいとき

  1. インターネットにつながった状態で、右上の人型ボタン → 設定を開きます。
  2. アプリのバージョンの更新を確認を押します。
  3. 新しいバージョンがあれば「新しいバージョン v○○ を取得しました」と出て、自動で再読み込みされます。「最新です」と出たら更新は不要です。
  4. 表示が新しいバージョンにならないときは、もう一度更新を確認を押します。

自動で更新されないとき

  • iPhone・iPad:ホーム画面のアプリは、閉じたつもりでも裏で動き続けていることがあります。画面下から上へスワイプしてアプリ一覧を出し、PDF Filesを上へはじいて完全に終了してから、もう一度開きます。
  • Windows・Mac・Android:PDF Filesのウィンドウをすべて閉じてから開き直します。ブラウザで使っている場合は再読み込み(Ctrl+R、Macは ⌘+R)します。
更新してもデータは消えません履歴・編集中の内容・印影・ログイン情報は更新後もそのまま残ります。アイコンや名前の変更は、端末によっては反映まで時間がかかることがあります。すぐに変えたいときは、一度アンインストールして入れ直します(その場合は次の注意を読んでください)。

15アンインストール

先に保存してくださいアンインストールすると、その端末に保存されている履歴・まだ保存していない編集内容・印影・端末内だけのアカウント情報が消えることがあります。必要なPDFは、先に保存・出力で元のファイルやGoogleドライブに保存してください。Googleドライブに保存したファイルと、Buildsと共通のアカウントは消えません。

iPhone・iPad

  1. ホーム画面のPDF Filesのアイコンを長押しします。
  2. Appを削除(またはブックマークを削除)を選び、削除を押します。

ホーム画面のアプリの保存データも一緒に削除されます。

Windows・Mac Chrome

  1. PDF Filesを起動し、ウィンドウ右上の︙メニューを開きます。
  2. PDF Filesをアンインストールを選びます。
  3. 保存データも消すときはChromeのデータも削除するにチェックを入れ、削除を押します。

Windowsでは、設定 → アプリ → インストールされているアプリからも削除できます。

Windows・Mac Edge

  1. Edgeのアドレスバーに edge://apps と入力して開きます。
  2. PDF Filesの︙(詳細)からアンインストールを選びます。

Android

  1. ホーム画面かアプリ一覧のPDF Filesのアイコンを長押しします。
  2. アンインストール(または削除)を選びます。

Mac Safari(Dockに追加した場合)

  1. Finderでアプリケーションフォルダを開きます。
  2. PDF Filesをゴミ箱に入れます。

ブラウザに残ったデータも消したいとき

ブラウザで直接開いて使っていた場合は、ブラウザの設定で公開URLのサイトデータ(Cookieとサイトデータ)を削除すると、端末内の履歴や印影が消えます。

17困ったとき

書き込んだ内容が消えないか心配です
編集内容は端末の中に自動で一時保存されます。アプリを閉じても、履歴から開くで続きから作業できます。ただし元のファイルには保存されていないので、最後に保存・出力で保存してください。
「どちらを開きますか?」と聞かれました
端末に保存していない編集内容があるのに、元のファイルがほかのアプリなどで書き換えられているときに出ます。書き込みを続けたいなら編集中の内容を開く、新しいファイルを見たいならファイルの最新を開く(編集内容は破棄されます)を選びます。
メールで「添付が大きすぎます」と出ます
Gmailの添付は約24MBまでです。最適化を最小にして送り直してください。
Googleドライブやメールが使えません
インターネットにつながっているか確認してください。オフライン中の保存や送信は「待ち」に入り、オンラインに戻ったら実行できます。うまくいかないときは設定 → Googleの接続を解除のあと、もう一度Googleにログインしてください。
新しい機能が表示されません
バージョン更新の更新を確認を試してください。
使っているバージョンを知りたい
設定のアプリのバージョンに表示されています。
